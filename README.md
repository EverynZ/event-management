# Event-Management.app

React aplikacija za organizaciju vjenčanja, krštenja i rođendana.

Autor: Everyn Zagorec Mrđa

## Entiteti (CRUD nad sva tri)

- **Klijent**: ime, e-mail, telefon (tko naručuje)
- **Objekt**: naziv, grad, adresa, kapacitet, cijena (gdje se održava)
- **Narudžba**: vrsta (vjenčanje, krštenje, rođendan), datum, klijent, objekt, broj gostiju, status, napomena

Podaci se spremaju u `localStorage` preglednika.
